# Evaluation Layer — Phase 4

The QualityEvaluator is the quality gate of BrandOS.

It scores each generated asset against:
- Brand consistency (does it match the brand voice and values?)
- Grammar and clarity
- Completeness (are all required sections present?)
- Tone (does it match the intended tone?)
- Readability (appropriate reading level for the audience?)

All scores are 0.0–1.0. Pass threshold is 0.7.
